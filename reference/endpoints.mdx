# Endpoint index

All paths below are relative to the base URL for your integration. The list follows the 30 operations in API v2.13.

## Authentication

| Operation | Path | Purpose |
| --- | --- | --- |
| Login | `POST /api_order/login` | Obtain a verification token. |

## eSIM catalog and orders

| # | Operation | Path | Purpose |

| 2.3 | Get SKUs by continent | `POST /api_esim/getSkuByGroup` | Group SKUs by continent. |
| 2.4 | Get packages by SKU | `POST /api_esim/getPackages` | List packages supported by a SKU. |

## Production URLs

For overseas integrations, prepend:

```text
https://bpm.roamesim.net
```

The v2.13 supplier document lists `http://bpm.roamwifi.com` for mainland China and lists HTTP for two legacy ICCID endpoints. Confirm regional routing with MIOeSIM before production use and prefer HTTPS for sensitive data.
