# MIOeSIM API documentation

This repository contains the Mintlify developer documentation for the MIOeSIM BPM API.

The reference is based on **ESIM API Documentation v2.13**, revised **22 July 2026**. The supplier PDF itself is not redistributed here because it is marked confidential; credentials and test keys are also excluded.

The public documentation covers authentication, request signing, all 30 documented operations, physical-SIM support, ICCID lookup/history, and the v2.13 usage-synchronization endpoint.
